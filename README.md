# pinn-cantilever-beam
A Physics-Informed Neural Network (PINN) in PyTorch to solve the 4th-order Euler-Bernoulli beam equation.

This project is a hands-on implementation of a Physics-Informed Neural Network (PINN) in PyTorch to solve a classic 4th-order differential equation from solid mechanics: the Euler-Bernoulli beam theory.

The goal was to build an AI model that could discover the correct physical deflection of a beam, using only the governing physics equation(Euler-Bernoulli beam equation) and boundary conditions as its guide (no FEA data was used for training).

The final PINN prediction achieved a 0.19% relative error at the beam's tip compared to the exact analytical solution.

(The final comparison plot, generated by the notebook, showing the PINN, FEA, and Analytical solutions in perfect agreement.)

The Three-Method Comparison
This repository solves one problem in three different ways to validate the PINN's performance:

📚 Analytical Result: The exact textbook solution derived from the Euler-Bernoulli equation: d(x) = (w * L^4) / (8 * EI) 

💻 FEA Result: A numerical simulation using the open-source FreeCAD modeler and Calculix solver. The raw data from this simulation (calculix.dat) is included in this repository.

(Screenshot of the FEA model setup in FreeCAD)

🧠 AI (The "PINN"): The PyTorch model in the main Jupyter Notebook (pinn_beam_solver.ipynb). It was trained to satisfy the physics loss (d'''' = 1 in normalized coordinates) and the four boundary conditions (d(0)=0, d'(0)=0, d''(L)=0, d'''(L)=0).


A naive implementation of this PINN fails spectacularly. The training loss explodes or crashes with nan (Not a Number) errors. The key to the solution was Normalization (Non-Dimensionalization). By scaling the inputs and outputs to a "calm" numerical range [0, 1], the optimizer (Adam + L-BFGS) could successfully navigate the complex loss landscape and converge to the correct physical solution.

All the math, debugging steps, and the "Aha!" moments of this process are documented in the main Jupyter Notebook.

How to Run:
This project is contained entirely within the pinn_beam_solver.ipynb Jupyter Notebook.

Files in this Repository:
pinn_beam_solver.ipynb: The main Jupyter Notebook with all code (training and plotting).
calculix.dat: The raw data exported from the FEA simulation.
Freecad_Calculix_Setup.png: A screenshot of the FEA model setup.
Freecad_Calculix_Results.png: A screenshot of the FEA results.
Paraview_results.png: The final comparison plot.

Requirements: torch, numpy, matplotlib (e.g., pip install torch numpy matplotlib)

Instructions:

Ensure calculix.dat is in the same folder as the notebook.

Open pinn_beam_solver.ipynb in Jupyter Lab, Jupyter Notebook, or VS Code.

Run the first cell: This cell contains the entire PINN definition and the two-phase (Adam + L-BFGS) training process.

Run the second cell: This cell loads the trained model, loads the calculix.dat, and generates the final 3-way comparison plot.
